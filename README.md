# Plantix Frontend

A TypeScript-based frontend for the Plantix project.

## What this repo is
This repository contains the frontend code for Plantix — a web client for plant health / care features. The codebase is written primarily in TypeScript, with CSS for styling and other assets.

## Quick start (example)
1. Clone the repo:
   git clone https://github.com/PUSHPAK-JAISWAL/Plantix_Frontend_Code.git
2. Enter the project directory:
   cd Plantix_Frontend_Code
3. Install dependencies:
   npm install
   or
   yarn install
4. Start the dev server:
   npm run dev
   or
   yarn dev
5. Build for production:
   npm run build
   or
   yarn build
6. Run tests:
   npm test
   or
   yarn test
